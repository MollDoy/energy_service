# Backend проекта "Веб-сервис сбора и анализа статистической информации цен на электроэнергию"

## 1. Общая архитектура

Бэкенд проекта написан на Python с использованием фреймворка Flask. Он отвечает за:
- получение и обработку данных о ценах на электроэнергию,
- взаимодействие с базой данных,
- предоставление API для фронтенда,
- выполнение математических расчётов и генерацию статистики.

## 2. База данных

В проекте используется реляционная база данных (PostgreSQL). Основная таблица выглядит следующим образом:

![Структура таблицы базы данных](../images/ИИТИАД.drawio.png)  <!-- Здесь можно вставить скрин или схему -->

Таблица содержит следующие поля:
- `id` — уникальный идентификатор записи;
- `date` — дата наблюдения;
- `region` — регион поставки электроэнергии;
- `price` — цена электроэнергии;
- `volume` — объём потребления;
- и другие поля, необходимые для анализа.

## 3. Файлы проекта

### 3.1 `app.py`

Главный файл приложения. Содержит:
- инициализацию Flask-приложения,
- подключение к базе данных через SQLAlchemy,
- регистрацию маршрутов API для фронтенда,
- обработку запросов и возвращение данных в формате JSON.

Пример кода:

```python
from flask import Flask, jsonify
from models import db, EnergyData
from fetch_data import get_latest_data

app = Flask(__name__)
app.config.from_object('config.Config')
db.init_app(app)

@app.route('/api/data', methods=['GET'])
def get_data():
    data = EnergyData.query.all()
    return jsonify([d.to_dict() for d in data])

if __name__ == "__main__":
    app.run(debug=True)
